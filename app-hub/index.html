App Hub

One place to see whether every app is current. App Hub lists my apps with the version on the phone next to the latest release and its notes, checks once a day, and gets an update with one tap. Before anything installs, it checks that the file is genuine, and Android still asks you to confirm.

Personal project · Not publicly available yet

What it does

A small, original companion to the other apps. The other apps' About screens have a Check for updates button that opens App Hub on their page.

Every app, one list

Wrangell Daily, Phone Gallery, Tidewater Money, DeskLink, Phone Trackpad and App Hub itself, each with what's installed, the latest release and a clear status.

Release notes

Each app's page shows what changed in its latest version before you update.

One-tap updates

App Hub downloads the update and hands it to Android's installer. Android always shows its own Install prompt, so nothing changes without your OK.

Checked before installing

Every download must match its published checksum and be signed with the same certificate as the app you already have. If anything is off, it's deleted and not installed.

A daily check

Once a day, when there's a connection, it looks for new versions and sends one notification per update.

Notify or download

Per app: just tell me, or download and check it in the background (on Wi-Fi by default) so it's ready to install.

Not installed yet?

Apps that aren't on the phone yet can be installed from the same list.

The Windows companion

Phone Trackpad's Windows app is listed with its latest version, for information.

Private and read-only

It only reads release information, keeps its sign-in encrypted on the phone, and sends it nowhere else. No tracking.

Light and dark

Follows the phone's dark or light setting.

Screenshots

Tap any screenshot to enlarge it. They're shown in dark mode, the default; “Light mode” under a screenshot opens the light version. Versions, dates and download progress are example data, and sign-in screens are left out.
