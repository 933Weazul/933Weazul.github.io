Windows 10 and 11 · Desktop button

Cast to Roku

Want the laptop on the big screen? Double-click Cast to Roku on the desktop. It opens the Windows Cast panel, the same one as Win+K, waits for the Roku to show up and connects to it, so there's no hunting through the list.

Personal project · Not publicly available

What it does

A short script behind a desktop shortcut. It uses the casting that's built into Windows; there's nothing to install on the TV.

One double-click

Opens the Cast panel and picks the first wireless display whose name contains “Roku”.

Waits for the TV

Windows can take a few seconds to find the Roku, so it keeps looking for up to 25 seconds.

Your Roku, your name

If the Roku shows up under a different name, one setting tells the button what to look for.

Fails gently

If no matching display appears, it says what to check and leaves the Cast panel open so you can pick one yourself.

Nothing installed

No administrator rights, no settings changed and no internet use. Remove the shortcut and it's gone.

Picture

A drawn illustration, not a screen capture; the display names are examples. Shown in dark mode; “Light mode” opens the light version.

Cast to Roku is a personal project and isn't publicly available, and it hasn't been tried with a real Roku yet. It needs a PC that can cast to wireless displays (Miracast), and the Roku must allow screen mirroring. It isn't affiliated with Roku or Microsoft.
