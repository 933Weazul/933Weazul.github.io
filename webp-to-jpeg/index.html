Convert WebP to JPEG

Saved a picture from the web and it turned out to be a .webp that nothing else wants to open? Right-click it, choose Convert to JPEG, and a normal .jpg appears right next to it. No extra software, no administrator account, and the original stays as it was.

Personal project · Not publicly available

What it does

One small self-contained program and a right-click menu entry for your own Windows account.

Right there in the menu

Right-click a .webp file and choose Convert to JPEG. On Windows 11 it's in the classic menu, under Show more options.

Same folder, same name

photo.webp becomes photo.jpg. If that name is taken it writes photo-1.jpg, photo-2.jpg and so on, so nothing is overwritten.

Several at once

Select a handful of .webp files and convert them together.

Sensible results

JPEG quality 90. Transparent areas become white, and for an animated WebP the first frame is saved, with a note saying so.

No administrator needed

The menu is added for your account only, and removing it is one double-click.

Quiet when it works

The new file is the only sign. If something goes wrong, a message explains why.

Pictures

These are drawn illustrations, not screen captures. The menu wording matches what the tool adds, and the thumbnails in the second picture are real files converted by the tool's own code. Shown in dark mode; “Light mode” opens the light version.

Convert WebP to JPEG is a personal project and isn't publicly available. It runs on 64-bit Windows 10 and 11 on Intel or AMD PCs. Camera info and colour profiles aren't copied into the JPEG. It isn't affiliated with Microsoft or Google.
